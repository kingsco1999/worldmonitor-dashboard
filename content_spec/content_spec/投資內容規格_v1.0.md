## 一、事件分類法 + 傳導矩陣（規則庫核心）

### 1.1 使用方式
- 新聞/事件進來 → 分類器歸入事件型（E1-E12 + 個股事件 P 系列）→ 查矩陣取出每個資產嘅方向+強度 → 驅動地球弧線、資產標籤、Brief 入選
- 方向全部條件式：「若事件發生/升級 → 資產方向」，唔係預測
- 強度 5 級：↑↑/↓↓ 強烈、↑/↓ 溫和、— 中性（判定門檻見 §1.4）

### 1.3 每個事件型嘅一句邏輯 + 二級傳導（1-3日）

- **E1 中東武裝升級**：霍爾木茲海峽承載全球約 20% 石油海運量，直接交火觸發供應中斷風險定價。二級：通脹預期升→美債收益率升、航空股受壓。72h 無進一步升級，油價風險溢價通常回吐一半以上。
- **E2 航道封鎖**：供應休克→滯脹交易；油單日 >5% 先列 ↑↑。二級：新興市場貨幣貶值、減息預期降溫。
- **E3 紅海中斷**：摩擦性但持久，主要影響集裝箱運價（繞道好望角 +10-14 日），對原油影響弱，同 E2 區分。
- **E4 台海升溫**：全球 90%+ 先進半導體產能集中台灣，台積電係科技業單一系統性節點。軍演/演習級別 → ↓；實體封鎖/交火 → ↓↓。日元同時有避險升值。
- **E5 俄烏升級**：歐洲能源（TTF 天然氣）+ 糧食（小麥）雙通道；核威脅言論 → 金 ↑。
- **E6 關稅升級**：關稅本質係成本稅→物價升+企業利潤跌。中美關稅→港股/科技/供應鏈 ↓↓；鋁鋼關稅→工業機械成本升（TEX 相關）；美歐關稅→歐洲汽車/奢侈品 ↓。
- **E7 制裁/出口管制**：被制裁板塊 ↓↓、國產替代受惠；金融制裁動搖貨幣體系→黃金中長線受惠（儲備多元化）。
- **E8 央行鷹派意外**：實際利率升→金/成長股估值受壓；⚠️ 日本央行意外加息觸發套息交易拆倉時，全球風險資產可跨市場連鎖急跌（2024-08 先例），BTC 同跌。
- **E9 央行鴿派意外**：E8 反向；流動性預期改善→金、成長股、BTC 齊升。
- **E10 衰退數據**：油暴跌（需求崩塌）+ 收益率急降（湧入美債）+ VIX 升 = 衰退交易；防禦板塊（醫藥/公用）相對抗跌。
- **E11 金融爆煲**：傳染確認信號 = SOFR 隔夜利率 spike、銀行 CDS 急升；初期美元因流動性需求反而升。
- **E12 停火降級**：E1/E2/E5 反向，避險溢價回吐；若市場已 price 停火卻再破裂，強度升一級。

**個股事件（P 系列，唔入宏觀矩陣，歸入持倉歸因雷達）：**
- P1 業績公佈/盈警｜P2 併購/回購/大股東增減持｜P3 監管/訴訟/調查｜P4 大行評級變動
- 處理：只影響該持倉 + 同板塊標籤，唔驅動地球弧線

### 1.4 強度判定門檻

↑↑/↓↓ 須同時滿足：
1. 單日波動 ≥ 該資產 20 日 ATR 嘅 3 倍
2. 絕對門檻：商品/股指 ≥±3%、外匯 ≥±1.5%、VIX ≥+30%、個股 ≥±6%
3. 一級傳導路徑（路徑短）+ 歷史同類事件同向比例 ≥70%

↑/↓：波動 1-3 倍 ATR；商品/股指 ±1-3%、外匯 ±0.5-1.5%、個股 ±3-6%；或屬二級傳導。
— 中性：路徑唔直接 / 歷史反應不一致 / 事件已被市場定價。

動態調整：同類事件 30 日內第 2 次出現自動降一級（市場習慣化）；事件與市場既有定價相反（如已 price 停火卻再升級）升一級。

## 二、每日 Brief 模板

### 2.1 通則
- **5 點為上限**（超過 = 編輯失敗）；**每點 ≤40 個中文字**
- 每點格式：`[標籤] 事實一句｜如果…就…`
- 排序：🔴風險事件 > 💼持倉異動 > 🥇核心資產 > 📊風險溫度 > 🌏地緣
- 純事實陳述（無條件/無行動含義）唔入 Brief；Brief 永遠置頂
- 評論/分析文章唔入 Brief（只入新聞 feed）

### 2.2 晨版（開市前，~07:57，面向「今日點部署」）

```
📋 晨間 Brief｜M月D日（星期X）
1. 🔴 [最迫近高風險事件+時間]｜如果[條件]，就[EA動作/時間]
2. 💼 [持倉異動：邊隻±幾多%]｜如果[歸因/無歸因]，就[處理方式]
3. 🥇 [金/銀/油現價+位置]｜如果[今日催化劑]，就大概率[方向/關鍵位]
4. 📊 [風險溫度分數+regime]｜如果[指標變化]，就[倉位動作]
5. 🌏 [真實地緣升級→受影響資產]｜如果無升級，就換「今日關注板塊」
```

**真實範例：**
```
📋 晨間 Brief｜8月27日（星期四）
1. 🔴 20:30美國PCE+GDP、21:00 Jackson Hole開幕｜如果20:00前未收EA，就暫停至22:00
2. 💼 SBTU上日-15%⚠️｜如果SBET無新公告，就按2倍槓桿波動處理
3. 🥇 金$4,503回調3.4%｜如果Powell放鴿，就大概率反彈試$4,580
4. 📊 溫度58分中性｜如果VIX升穿20，就暫停高beta持倉
5. 🛢️ 油$83.5企穩｜如果中東無新升級，就維持區間判斷
```

### 2.3 晚版（收市後，~21:09，面向「美股發生咩+聽日部署」）

```
📋 晚間 Brief｜M月D日
1. 📊 [美股收盤：SPX/NDX漲跌+一句主因]｜如果[延續條件]，就[聽日傾向]
2. 🔴 [聽日/未來12h高風險事件+EA窗口]
3. 💼 [持倉當日表現+異動歸因]
4. 🥇 [金/銀/油收盤+最近觸發點距離%]
5. 🌏 [地緣/資金流嘅資產含義] 或 [加密異動]
```

**真實範例：**
```
📋 晚間 Brief｜8月26日（星期三）
1. 📊 SPX+0.6%創新高、NDX-0.7%分化｜如果輪動持續，就聽日留意價值股
2. 🔴 聽日20:30 PCE+GDP、21:00 Jackson Hole｜聽日20:00起暫停EA
3. 💼 VEEV-1.9%跟隨SaaS板塊｜如果利率預期再升，就繼續受壓
4. 🥇 金$4,503、銀$67.1、金銀比67.1｜如果金銀比跌穿66，就白銀轉強
5. ₿ BTC $77,929橫行｜如果美股回落，就留意會否同步走資
```

### 2.4 持倉異動規則
- 單日 ≥3%：強制入 Brief + ⚠️，自動觸發歸因搜索
- 單日 ≥6%：標紅 + ntfy 即時推送（唔等早晚版）
- **SBTU 特殊**（2 倍單日槓桿 ETF，日常波動極大）：≥6% 先入 Brief、≥12% 先即時推送；歸因搜索關鍵字用 **SBET（SharpLink Gaming）**，唔搜 SBTU
- 歸因失敗：寫「⚠️ 未尋獲明確歸因，需人工查證」，**禁止編造**

### 3.3 總分 → Regime

| 總分 | Regime | 狀態 | EA / 倉位含義 |
|---|---|---|---|
| 0–30 | 🟢 進攻模式 | Risk-On | EA 正常運行，趨勢策略順風 |
| 31–60 | ⚪ 中性 | Neutral | EA 正常，但避開 🔴 事件窗口 |
| 61–80 | 🟠 避險模式 | Risk-Off | 建議暫停高 beta EA、收窄倉位 |
| 81–100 | 🔴 極端避險/危機 | Crisis | 全部 EA 暫停，僅保留觀察 |

**防反覆規則：**
- 連續 2 次生成（晨/晚）分數越過閾值先正式切換 regime，避免單日噪音反覆
- 但總分 >80 即時生效，唔需要等第二次
- **🔴 事件窗口優先於溫度計**：無論分數幾低，NFP/FOMC/Jackson Hole 等 🔴 事件前 30 分鐘 + 後 60 分鐘一律暫停 EA
- Regime 較上一次切換 → 強制入 Brief
